# 小行星锐评口吻版：国内个人用户视角，主观排名，不是完整实测


---

## 01. 封面

桌面 Agent App 这一波，终于不是“再给你一个聊天框”了。前两年 AI 工具的主战场，是你问一句，它答一段；后来变成你给代码，它帮你改。现在变化更大：Agent 开始坐进你的电脑里，读文件、点软件、开浏览器、跑脚本、生成表格和 PPT，还能把一个任务拆给几个子 Agent 并行做。听起来很夯，对吧？但对普通人来说，真正的问题不是“演示里有多神”，而是今天能不能下载、能不能订阅、够不够开放、用久了会不会贵到肉疼。这一期，我按国内个人用户视角，把桌面 Agent App 从夯到拉排一遍。


---

## 02. 标尺

先声明：这是小行星的主观锐评，基于公开资料、价格页、官方文档和产品体感判断，不是实验室实测。评分五刀：第一，上手交付效率，装上多久能拿到第一件真东西；第二，任务执行深度，会不会读文件、写文件、点软件、跑流程、长任务、多 Agent；第三，国内可获得性，能不能访问、订阅、支付、长期用；第四，开放度，能不能接自己的模型 API、接国产模型、本地模型；第五，价格与真实成本，月费、积分、额度、排队、加量包都算。复杂度要交租，带不走的能力也要打折。


---

## 03. 第八名 Claude Cowork

第八名，Claude Cowork。先别急着骂。只看产品完成度，它可能是这类产品的标杆：Claude 在你的电脑、本地文件和日常应用里干活，能读写文件，能拆子任务，能生成 Excel、PPT、文档，权限和虚拟机隔离也讲得比较清楚。但这期不是硅谷能力天梯，是国内个人用户榜。Claude Cowork 需要付费订阅，国内访问、支付、稳定使用都有门槛；模型也基本锁在 Claude 上。好东西，但门票难买，房租还贵。打个分：交付五星、深度五星、国内可得两星、开放一星、价格两星半。


---

## 04. 第七名 Google Antigravity 2.0

第七名，Google Antigravity 2.0。它算桌面 Agent App，但不是通用办公同事，而是开发者 Agent 指挥中心。Google I/O 2026 讲得很清楚：独立桌面应用，多 Agent 并行，动态子 Agent，定时任务，接 AI Studio、Android、Firebase。能力硬，方向也对。但它的问题同样硬：Google 生态国内可获得性弱，普通用户支付和稳定使用不顺；官方能选模型，但我没看到它支持接自己的模型 API，所以开放度按不支持处理。开发者可以关注，普通人别把它当办公神器。打个分：交付四星、深度四星半、国内可得两星、开放两星、价格四星。


---

## 05. 第六名 Codex App

第六名，OpenAI Codex App。对开发者来说，它非常夯：多 Agent 指挥中心、worktree、diff review、skills、自动化、computer use、Windows 和 macOS 都在推进。更关键的是，Codex 文档里明确说，可以指向支持 Chat Completions 或 Responses API 的任意模型或供应商，这一点比 Claude 开放得多。但扣分也很现实：国内普通人订阅、支付、稳定访问都麻烦；ChatGPT 登录和云任务体验仍然偏 OpenAI 体系；额度和 credits 会让真实成本变复杂。它不是差，是太像开发者的高性能工具，不像普通人的低摩擦桌面同事。打个分：交付四星半、深度五星、国内可得两星、开放四星、价格两星半。


---

## 06. 第五名 MiniMax Code

第五名，MiniMax Code。它主打 Agent Team：桌面端能跑多个 Agent，分角色协作，适合长任务。国内价格也漂亮：Plus、Max、Ultra 是人民币 Token Plan，49、119、469 元/月，积分包也有明确换算。这个性价比很能打。但它的短板是开放度：主线还是 MiniMax 自家生态，没有看到普通用户清晰接入外部模型的入口。它适合内容、研究、运营用户尝鲜长任务，不适合想掌控模型栈的人。打个分：交付四星、深度四星半、国内可得四星半、开放两星、价格四星半。


---

## 07. 第四名 Eigent

第四名，Eigent。开源 Cowork 桌面里，它是比较像产品的一个：有官网，有下载页，定位是 AI workforce，可以连接你的上下文，控制浏览器和桌面 App，还能自托管，用自己的 API key 或本地模型。这个方向我喜欢，因为它不给你租一个漂亮牢房，而是把钥匙递给你。问题也直接：开源桌面 Agent 现在最大的成本不是软件价格，是维护复杂度；它有下载入口和开源能力，但普通人要长期当主力，还得自己承担配置和维护。打个分：交付三星、深度四星、国内可得四星、开放五星、价格四星半。


---

## 08. 第三名 Open Cowork

第三名，Open Cowork。它的牌打得更直：开源版 Claude Cowork，Windows 和 macOS 一键安装，能包 Claude Code、OpenAI、Gemini、DeepSeek，支持 VM 隔离、Skills、MCP、GUI automation、飞书和 Slack 远程控制。它不是最丝滑的，但它很关键：你可以接自己的模型，可以把成本换成 API 成本，可以把能力带走。复杂度当然也会收租，尤其是 MCP、沙箱、模型配置这些东西，对普通用户仍然不是零摩擦。但在“国内个人用户 + 开放度”这个口径里，它必须排高。打个分：交付三星、深度三星半、国内可得四星半、开放五星、价格四星半。


---

## 09. 第二名 TRAE Work

第二名，TRAE Work。它强在把开发工具和办公工作台揉到一起：Desktop、Web、Mobile，Work 和 Code 双模式，能读 docx、csv、pptx、Python script，还能云端多任务并行。中国区价格也清楚：免费版能跑 2 个云端任务，Pro 99 元/月，新用户低至 59，Pro+、Ultra、Express 往上加。TRAE 官方文档明确写了：TRAE Work 桌面版可以添加自定义模型，但只支持本地环境；云端任务不算支持自己的模型。所以它有开放度，但不满血。对国内用户来说，它仍然是少数“今天就能试、价格看得懂、办公和代码都能碰”的产品。打个分：交付四星半、深度四星、国内可得五星、开放三星半、价格四星。


---

## 10. 第一名 WorkBuddy

第一名，腾讯 WorkBuddy。它不一定是能力最性感的，但它是这期最实用的。国内可用，人民币价格，自定义模型入口清楚，能选供应商、自定义 API、Token Plan、Coding Plan、Ollama、本地部署；个人版也有免费、99、199、999 元/月几档，连续包月更低。腾讯办公生态里，文档、会议、企业微信这些入口本来就在用户身边，所以它更像真的能落地的桌面同事。缺点也别装看不见：腾讯生态味很重，积分体系复杂，长期会不会被生态绑定，需要警惕。但在这期五刀里，它交的租最少，能带来的产出最现实。打个分：交付四星半、深度四星、国内可得五星、开放五星、价格四星。


---

## 11. 总榜

总榜收一下：第一 WorkBuddy，第二 TRAE Work，第三 Open Cowork，第四 Eigent，第五 MiniMax Code，第六 Codex App，第七 Google Antigravity 2.0，第八 Claude Cowork。记不住没关系，记住三句话就够：普通人先看 WorkBuddy 和 TRAE；想要开放和可迁移，看 Open Cowork 和 Eigent；开发者再看 Codex 和 Antigravity。Claude Cowork 产品很强，但等你能稳定订阅再说。


---

## 12. 怎么验证

再强调一次，这是主观榜，不是实测铁律。你真要上手验证，别问它“你是谁”，那是浪费时间。就跑四个任务：一堆资料生成 PPT，一个 CSV 清洗分析出图，一个网页调研并标来源，一个本地文件夹整理重命名归档。看三件事就够：它能不能少问废话，能不能交出成品，出错以后你能不能改得动。能过这三关，才值得长期放在电脑里。
