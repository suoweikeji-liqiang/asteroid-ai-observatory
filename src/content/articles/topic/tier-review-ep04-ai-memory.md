## 01. 封面

接着上一期的问题往下走。这一期我们聊 AI 的记忆系统——就是让 Agent 不再每次都失忆的那层东西。市面上号称"给 AI 装记忆"的项目越来越多，今天我把七个真正的记忆引擎摆上台，从夯排到拉，看看谁是真记忆，谁只是把聊天记录又塞回了提示词。


---

## 02. 开场

先说清楚，记忆不等于长上下文，也不等于检索增强，这些我们专题里讲透过，这里不重复。今天只看产品：谁真的把记忆分层、写回、遗忘、治理做进了引擎，谁还停在给你存一份用户画像。还有一件事讲在前头——记忆引擎是给开发者装进 Agent 的后端，跟给人用的第二大脑不是一个物种，最后我会单独点名那几个，别混着比。


---

## 03. 评分标尺

六刀标尺。第一刀记忆纵深，是只记了个用户画像，还是做到了情节记忆、程序记忆，这一刀直接回答谁是真记忆。第二刀检索召回，该记的取不取得回。第三刀写回治理，会不会更新、去重、遗忘过期，防止记忆越用越脏。第四刀可控可迁移，开源是真开源还是半开源，记忆能不能导出带走。第五刀工程就绪，是能上生产还是还在实验室。第六刀生态集成。总分是综合判断，不是六星相加。


---

## 04. 第七名 LangMem

第七名，LangChain 出的 LangMem。它是亲儿子，语义、情节、程序三类记忆概念上都给你留了口子，挂在 LangGraph 上。但它更像一盒半成品零件，不是一套能开箱的记忆系统——存储要你自己接，抽取更新要你自己拼提示词，社区里"为什么我不再默认用它"的帖子一大把。灵活是真灵活，可控也高，代价是一切都得自己焊，还绑死了 LangGraph 生态。给它打个分：纵深三星、召回三星、治理两星、可控四星、就绪两星、生态四星。


---

## 05. 第六名 Memobase

第六名，Memobase，一个反着来的选手。别人都在堆向量库，它偏不用，只把用户聊出来的东西压成一张结构化画像，取回只要八十毫秒。它是这一榜记忆最浅的——基本只做用户画像这一层，没有情节记忆，也没有程序记忆。但我给它留了面子，因为它从不装成全记忆：明说自己就是个画像后端，全开源，一个容器就能起，快到离谱。很多号称全记忆的产品，扒开也就存了个画像，它至少诚实。给它打个分：纵深两星、召回三星、治理三星、可控四星、就绪五星、生态两星。


---

## 06. 第五名 Supermemory

第五名，Supermemory。它起家是个开源的第二大脑应用，用户很喜欢，后来转型成给开发者的记忆引擎 API，融了快三千万美元。毛病也出在这——记忆、检索、用户画像、各种连接器，全塞进一个盒子，什么都做一点，但没有哪一样是最深的那个。方便是真方便，上手和生态是它的强项，可记忆纵深不够顶。给它打个分：纵深三星、召回三星、治理三星、可控三星、就绪四星、生态四星。


---

## 07. 第四名 腾讯 Agent Memory

第四名，腾讯云数据库团队开源的 Agent Memory，用的是 MIT 协议，两个月拿了四千多颗星。当别人都在卷长期记忆，它先在短期记忆上玩了个新花样——把又臭又长的工具调用日志，压缩成轻量的 Mermaid 结构符号，官方说 token 最多能省下六成。长期那层做的是分层个性化记忆，在评测里把用户画像的理解准确率拉了上去。它是这一榜开源最干净的一个，全程 MIT，没有阉割；扣分只因为它太新，云端还得靠腾讯云向量库，自己部署这条路还年轻。给它打个分：纵深四星、召回三星、治理四星、可控四星、就绪三星、生态三星。


---

## 08. 第三名 Letta

第三名，Letta，就是当年 MemGPT 的正统续作。它把记忆分成核心、召回、归档三层，最狠的是 Agent 会自己改自己的记忆，还在往记忆原生强化学习上走。论记忆架构的深度，它是天花板级别的。但它的野心也是它的税——它不是一层记忆，是一整个 Agent 运行时，你想用它的记忆，基本得把整个 Agent 搬进它的框子里跑。想给现有系统外挂一层记忆的人，会嫌它重，嫌它锁。给它打个分：纵深五星、召回四星、治理四星、可控三星、就绪三星、生态三星。


---

## 09. 第二名 Mem零

第二名，Mem零，记忆层里最流行的那个。近五万颗星，两千多万美元融资，今年四月刚换了第三代算法，上了只增量抽取、混合检索加实体链接，是最稳的通用选择。生态最大、集成最多、上手最快。但它也有个开源阉割的小尾巴——你自己部署的 Python 版能用 Neo4j 图记忆，官方的那个 npm 包，却把图记忆锁在了云端付费模式。想白嫖图记忆，先看清你用的是哪个包。给它打个分：纵深四星、召回四星、治理四星、可控三星、就绪四星、生态五星。


---

## 10. 第一名 Zep / Graphiti

第一名，Zep，还有它的开源核心 Graphiti。它把记忆做成了一张会记时间的知识图谱：谁在什么时候说了什么，哪条事实什么时候失效，全都记在图上。这是这一榜里最接近真记忆的一个。它的核心是双时态知识图谱——旧事实不删除，只标记成从某个时间起失效，天然就把记忆的更新、冲突和污染给治了；论文里它的检索还打赢了 MemGPT。唯一别被忽悠的地方是：开源的是 Graphiti，那个抛光得很好用的 Zep Cloud 是闭源的，而且这张图得跑在 Neo4j 上，不算轻。给它打个分：纵深五星、召回五星、治理五星、可控三星、就绪四星、生态四星。


---

## 11. 总榜

七个记忆引擎，一张图收齐。要最强的记忆治理、扛得住知识图谱工程，看第一名 Zep；要通用、好接、社区大，绝大多数人选第二名 Mem零就够了；想从零搭一个有状态的 Agent，认它那套运行时，再上 Letta。中间那几个各有各的取舍，往下走越来越轻、越来越专，Memobase 最浅但最诚实。记住，这是记忆引擎之间比，别拿它们跟给人用的第二大脑硬凑一张榜。


---

## 12. 对照组 · 不是一个物种

最后单独点三个名字，它们经常被塞进记忆这个话题，但其实是另一个物种——给人、给组织用的第二大脑，不是给 Agent 装的引擎。Khoj，自托管的个人 AI 第二大脑，帮你搜文档、建助手；Basic Memory，把知识存成 Markdown 文件，本地优先，天生接 Obsidian 和 MCP；还有 GBrain，那是组织级的公司脑，我们专题线专门做过一整期，想深入的去看那期。它们和记忆引擎不冲突：引擎负责让 Agent 记住状态，第二大脑负责帮人沉淀资料，各司其职。
