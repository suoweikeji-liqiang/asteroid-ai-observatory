## 01. 封面 / 开场

这两个月，你大概反复听到一个词：自我进化 Agent。Hermes 说自己会越用越强，很多论文开始讲 self-evolving、在线强化学习，DeepMind 的 AlphaEvolve 甚至能用进化搜索发现新算法、优化真实的基础设施。听起来，AI 不但会干活，还会自己学习、自己进化。但这句话，如果不拆开，非常容易误导。


---

## 02. 先拆掉一个误解

因为今天大多数所谓的自我进化 Agent，并不是模型权重在你的电脑上自动训练，也不是模型每天自己变聪明。更准确地说，它们在进化的，是模型外部的系统结构：记忆、技能、轨迹、工具策略、评估器、还有整张 Agent 图。所以这期我们不做表层科普，不讲它会帮你发邮件、查网页、写代码这些功能。


---

## 03. 这期真正要拆的判断

我们真正要拆的是：Agent 的自我进化，到底发生在哪一层？哪些已经工程可用，哪些还只是研究方向？为什么这件事会成为今年 Agent 框架的主线？我先把结论放在这儿：短期，它不在模型权重里，而在模型外部的经验资产里。


---

## 04. 第一部分 · 从聊天框到常驻 Runtime

先看行业主线。这两年 Agent 的形态，正在从一个临时聊天框，走向一个长期运行的系统。


---

## 05. 五个阶段

第一阶段是聊天机器人，你问一句，它答一句。第二阶段是检索增强，它先查知识库，再回答。第三阶段是工具调用，它不只会说，还会调函数、查数据库、跑命令。第四阶段是工作流，人把流程编好，AI 按流程执行。而 Hermes、OpenClaw 这一类，开始进入第五阶段，常驻 Agent Runtime——它不是临时聊天框，而是一个住在你服务器上的长期系统，会记住学到的东西，运行越久越有能力。


---

## 06. 行业关心的问题变了

这说明大家关心的问题变了。过去我们问，模型能不能回答；后来问，模型能不能调用工具；现在开始问：Agent 能不能积累经验？能不能下次少犯同样的错？能不能从临时工，变成熟练工？所以它缺的，不是回答能力，而是一层可以累积经验的经验资产层。这才是自我进化 Agent 火起来的真正原因。


---

## 07. 第二部分 · 它能在哪些层进化

那要积累经验，Agent 到底能在哪些层上进化？我建议把"自我学习"拆成六层，从最浅，到最激进。


---

## 08. 六层技术图谱

第一层，上下文适配，把更多上下文塞进当前任务，但不代表长期变强。第二层，记忆，长期记忆、用户画像、项目事实。第三层，技能，把工作方法沉淀成程序性知识。第四层，轨迹，保存完整的执行过程。第五层，策略与模型，真正去更新模型或策略的参数。第六层，系统与架构，系统开始改工具、改代码、改自己的结构。


---

## 09. 工程可用 vs 研究想象

这个分类，能帮我们区分"工程可用"和"研究想象"。Hermes 和 OpenClaw，强在第二到第四层，是今天就能用的。OpenClaw-RL、SCoRe 这类，进到第五层，轨迹开始进入训练。而 AlphaEvolve、STOP、DGM，在第六层，是更激进的研究路线。把层分清楚，后面就不会被宣传词牵着走。


---

## 10. 第三部分 · Hermes 做对了什么

先看第一阶段里最好的工程样本：Hermes 真正做对了什么。


---

## 11. Hermes 的关键部件

Hermes 值得讲的，不是它接了多少平台，而是它把自学习的几个关键部件，放进了同一套 runtime：一个主循环，负责构建提示、调度工具、压缩上下文、保存会话；一套带全文检索的会话存储，能搜历史对话；一个记项目事实，一个记用户偏好；还有技能系统，Agent 可以自己创建、修改、删除技能。


---

## 12. 运行时自进化的闭环

所以 Hermes 的核心，不是某个单点功能，而是这个闭环：执行任务，产生轨迹，沉淀成记忆和技能，下次按需检索或注入，于是行为改变，再产生新的轨迹。注意，这里模型本身没有变。它不是在线微调，也不是强化学习自动更新权重，而是模型外部的经验资产在变。这就是运行时自进化，这个判断很关键。


---

## 13. 记忆、技能、轨迹不要混

很多人一讲 Agent 记忆就混成一团。专业地看，至少要分三类。记忆解决的是"知道什么"，比如这个项目的数据库在哪台服务器。技能解决的是"怎么做"，比如数据库连不上，按哪几步排查。轨迹解决的是"过去怎么做"，也就是那一次完整的记录：看到了什么、调了什么工具、哪里失败、怎么恢复。事实归记忆，流程归技能，过程归轨迹，混在一起，系统很快就乱。


---

## 14. 第四部分 · OpenClaw 本地 Agent OS

另一条值得看的路线，是 OpenClaw，它更像一个本地优先的个人 Agent 操作系统。


---

## 15. 行动敏感记忆

OpenClaw 最有价值的，是"行动敏感记忆"这个概念。普通记忆只记事实：这个项目要迁移接口。但行动敏感记忆要记边界：这次迁移还在另一个会话里设计，当前会话只能参考，不要直接改实现代码。这对企业很关键——因为记忆一旦会影响行动，它就不只是知识，而是权限的一部分。所以专业系统不能只问 Agent 记不记得住，还要问：这条记忆能不能触发行动？什么时候过期？谁授权的？


---

## 16. 为什么技能比记忆更重要

那为什么说技能比记忆更重要？记忆让 Agent 不必每次重新理解你，技能才真正让它越用越熟。Voyager 在 Minecraft 里，把成功的行为写成可执行的技能库，下次进新世界直接复用，这就是经验复利。但它也有反面：第一次路径要是错的，却被写成了技能，以后就会反复犯同样的错；而且技能里常带命令、路径、部署习惯，本身就是供应链风险。所以在企业里，技能不该自动进入可信状态，更稳的是走提案、人审、测试、小范围试用，再晋升。


---

## 17. 第五部分 · 把使用变成训练信号

前面讲的都是运行时的外部状态进化。再往前一步，就是把 Agent 的每一次使用，都变成训练信号。


---

## 18. next-state signal 与它的难点

OpenClaw-RL 的核心，是"下一状态信号"：用户的追问、纠正、点赞、否定，工具报的错，终端和界面的变化，测试的通过或失败，这些都是 Agent 动作之后，环境给出的反馈。它想从里面抽两类信号：这一步做得好不好，可以转成奖励；这一步该怎么改，可以变成监督。但最大的难点不是收集，而是信用分配和去噪——一个二十步的任务失败，真正的错可能发生在第三步。所以别一上来就上在线强化学习，先做轨迹存储、结果评估、离线回放和人工标注。


---

## 19. AgentEvolver 让 Agent 自己出题

更激进一点，是 AgentEvolver 这类系统，它想解决任务数据贵、随机探索低效。它提出三个机制：自我提问，自己生成挑战任务；自我导航，用过去的经验指导探索，不完全乱试；自我归因，给轨迹里不同的动作分配不同的贡献。Hermes 是你用它、它记住，AgentEvolver 是它主动提问、主动探索、主动归因。很有想象力，但真实的服务器、生产设备不是游戏环境，这类方向最适合先落在仿真、数字孪生、沙箱仓库和离线评测集里。


---

## 20. 自我奖励，监督瓶颈没有消失

还有一条路线，是自我奖励和自我纠错。自我奖励的想法是：如果模型能力超过人类，人类反馈会变成瓶颈，那能不能让模型自己当裁判，给自己反馈？SCoRe 则是用在线强化学习，训练模型自我纠错。这些方向很重要，但不能神化——因为模型自己评价自己，并没有消灭监督问题，只是把它转移了：原来问人能不能评估模型，现在变成模型能不能可靠评估自己，会不会强化自己的偏见，会不会钻奖励的空子。所以自我奖励不是不要外部评估，而是需要更强的评估体系。


---

## 21. 第六部分 · 真正稳的进化靠评估器

那有没有真正稳的自我进化？有，但关键不在模型，在评估器。这一点，AlphaEvolve 必须讲。


---

## 22. AlphaEvolve 的系统结构

很多人把 AlphaEvolve 讲成"AI 自己发明了新算法"，但专业上更重要的，是它的系统结构：人来定义问题、初始程序和评价指标，大模型生成程序的改动，评估器执行并打分，候选进入数据库，进化循环继续变异和筛选。它不是让模型一次性悟出答案，而是把模型放进一个有自动评分、有候选池、有进化选择的搜索系统。所以它给整个行业最大的启发是：自我进化，必须绑定可验证的环境——没有评估器的自我进化，只是在自动积累；有了评估器、候选池和回滚，才开始像真正的进化。


---

## 23. 更前沿也更危险 · 系统改自己

再往前走，是系统开始改自己。STOP 让外部的脚手架程序，改进自己的搜索策略，模型不变。GPTSwarm 把 Agent 看成一张可优化的计算图，既能改节点的提示，也能改图的结构。Darwin Gödel Machine 更激进，让 Agent 修改自己的代码，再用基准测试验证。方向很清楚：模型只是 Agent 的一个组件，能力还来自工具、流程、图结构和评估器。但这也是风险最高的路线——一旦系统能改自己，就必须问：它能不能绕过沙箱？改完谁来验证？谁批准上线？失败怎么回滚？


---

## 24. 第七部分 · 越自学习，攻击面越大

所以最后，必须讲安全。一个自学习 Agent 越强，它的攻击面就越大。


---

## 25. 经验污染与延迟触发

因为它不只是一次提示，它有记忆、技能、定时任务、工具、浏览器、文件系统。这意味着，恶意输入可能不在当下生效，而是先被写进记忆、技能或一个计划任务，几天后在另一个上下文里被触发——这就是"潜伏通道"的风险。研究里的 MemoryGraft 也指出，攻击者可以把有毒的"成功经验"，种进 Agent 的长期记忆，之后相似任务一检索出来，Agent 就会模仿这些危险模式。所以自学习一定要配套：来源标记、审批、沙箱、审计日志、回滚、可信技能登记，还有记忆晋升门。否则，越自学习，越不可控。


---

## 26. 真正有价值的判断

回到开头那个问题：Agent 的自我进化，到底是不是真的？我的判断是——短期是真的，但不是大多数人以为的那种真。它不是模型自己在线变成更强的模型，而是 Agent Runtime 开始拥有外部的经验结构。Hermes、OpenClaw 是第一阶段，运行时积累经验；OpenClaw-RL、SCoRe 是第二阶段，轨迹和反馈进入训练；AlphaEvolve、DGM 是第三阶段，系统开始搜索和改进自己。一句话：Agent 真正的自我进化，短期不在模型权重里，而在模型外部的经验资产里。
