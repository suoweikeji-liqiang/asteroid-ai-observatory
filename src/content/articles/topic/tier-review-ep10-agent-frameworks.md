## 01. 开场钩子（cover）

做 agent 这件事，过去一年变了天。但我发现一个通病：很多人一上来，就给自己一个小功能，套上一个又重又复杂的框架——拿高射炮打蚊子。其实"写代码搭 agent"的工具，是一条从薄到重的光谱：薄的几百行、你全掌控，重的一整套、它替你扛。这一期，工具标榜线的收官之作，我把这条光谱上的十个工具从夯到拉排个段位，但真正想帮你回答的，是那个更实在的问题：你手上这个活，到底该上多重。


---

## 02. 决策阶梯·你在哪一层（起）

先看清你站在哪。做一个 agent 应用，第一个硬分叉：想不想写代码。不想写、要快，就用 agent 平台，Dify、Coze、百炼这些，拖拖拽拽、它托管、你是用户，我们前面好几期都碰过——但平台会框死你：定制有限、代码多半拿不走。想要代码所有权、想深度定制，你就得下沉到今天这一层：自己写代码搭。而这一层不是二选一，是一条光谱——从薄薄的一个 SDK，到重重的一整套框架。今天，就带你把这条光谱走完，告诉你该站在哪一段。


---

## 03. 先给结论（承接暴论）

下沉到"写代码"这层，结论先摆出来。第一，暴论：别一上来就上重框架。你自己一个小功能、一个内部小工具，一个薄 SDK、甚至几百行的极简内核就够了，硬套重框架，是给自己找罪受。第二，那到底该上多重？我给你四个信号，撞到了，才值得往重的一端走。第三，段位：这条光谱上的十个工具，我按五个维度从夯到拉排好了，一会儿从垫底倒着揭到榜首。第四，收官：这是工具线最后一期，工具正在被商品化，护城河已经上移到 skills，下一条线，我们去拆 skills。


---

## 04. 光谱两端·控制反转（承）

这条光谱两端，差在一个词：控制反转，说白了就是谁开车。薄的一端，习惯叫 SDK：主循环是你自己写的，要哪个能力就调哪个函数——你开车，它在副驾递工具。这一端的代表，是 pi-agent-core、OpenAI Agents SDK。重的一端，习惯叫框架：你只声明结构，它掌管整个主循环——它开车，你在副驾指方向。代表是 LangGraph，你画一张状态图，剩下的执行、重试、恢复，它替你跑；还有 CrewAI、AgentScope。中间两栖的，是 Pydantic AI、Agno、Mastra。别纠结名字：OpenAI 那个叫 SDK 其实挺框架、Pydantic 叫框架其实很库——看的是你交出多少控制权。交得越多，它帮你扛得越多，也把你绑得越死。


---

## 05. 边界·谁在这条光谱上（承）

钉个边界，免得一锅浆糊。今天这榜，只收"写代码搭 agent 的库"这条光谱上的选手。三类长得像、但不是，点名出榜。一，成品编程 agent：opencode、Claude Code、Codex，它们是"读仓库、改文件、跑命令"的成品，是编程 agent 本身，不是给你搭 agent 的库。二，可视化平台：Dify、Coze，那是不写代码的上一层、前面几期讲过的事。三，记忆层、还有会自我进化的成品 agent，各归各线。都不在今天这张榜里。


---

## 06. 该上多重·四信号（转）

好，回到最实在的问题：这个活，该往光谱哪一端站？就看四个信号。四个一个都没咬到你——你就是做个小功能、小工具、小项目——那薄的一端就够了，别自找复杂。撞到一个、或几个，才值得往重框架走。信号一，多供应商路由：你的生产流量要同时跑在不止一家模型厂商上。信号二，多 agent 编排：问题真拆成了带交接、分支、人工审批的好几个 agent。信号三，确定性类型：你需要围绕输入输出的强 schema 和严格校验。信号四，生产级可观测：你要的评估、回放、追踪，超出了薄 SDK 自带的范围。记住：不是要不要上框架，是该上多重——需求多重，工具就多重。


---

## 07. 五轴·怎么打分（转）

真要往重的一端走了，我按五根轴给这十个工具打分。先说清楚：不实测跑分，只评工具本身、不评模型聪不聪明。第一轴，核心编排力：状态、恢复、人工审批，能不能把复杂流程稳稳跑完。第二轴，生产企业就绪：沙箱、多租户、权限、可观测、弹性部署，能不能安全上企业生产。第三轴，不锁模型：换厂商、换云容不容易。第四轴，上手和克制度：干净积木还是样板地狱。第五轴，落地和活性：版本活不活、有没有真实战、会不会明天就停更。十个，从垫底开始揭。


---

## 08. 第10名·垫底 · CrewAI（合·敢黑）

先揭垫底。第十名，CrewAI，一家同名美国创业公司做的、偏重的框架。五万五千星，是这榜里最网红的一个，角色化多 agent、上手极快、社区巨大，落地活性这轴满分。但星多不等于工程强：核心编排力上，它主见很重、大规模和调试是短板；更根本的是，"多 agent 军团"这套本身收益就存疑，很多团队实测下来，除了多烧钱、多一层幻觉、多爆几次上下文，好处相当有限。人气在夯档，工程在拉档，综合我把它压到垫底。红得发紫，不代表值得你押注。


---

## 09. 第9名 · Eino（合·国产·争议）

第九名，字节的 Eino，偏重的一端。国产里的一张硬牌：Go 语言写的，在抖音和豆包的生产环境里跑了半年，实战背书这一块，别人比不了。但它卡在一个定位争议上——它同时抄了 LangGraph 的图编排、和谷歌 ADK 的两套范式，两套底层还不一样，社区一直在问：会不会最后，谁都不如谁。加上 Go 在 agent 圈本来就小众，生态和案例还薄。实战分很高，定位分打折，第九。


---

## 10. 第8名 · Mastra（合）

第八名，Mastra，站在光谱中间、库和框架都占点。它来头不小——是做过前端明星框架 Gatsby 的原班团队搞的，还拿了 YC 的投资。主打 TypeScript，最大卖点是"电池全含"，这词的意思是：记忆、可观测、部署这些你常用的零件，它全都内置好了，你不用自己东拼西凑、装一堆依赖，开箱就是一整套，前端和全栈的同学用它最顺手。它的问题不在能力，在年龄：整个生态还年轻，版本迭代快、长期稳定性还要再看，复杂工作流上也没经过足够多的大生产捶打。语言选型对了就很香，但放进全池子比工程厚度，还排不到更前。第八。


---

## 11. 第7名 · Google ADK（合）

第七名，谷歌的 ADK，偏重框架。事件驱动、代码优先，多 agent 和长任务的设计很正统，企业级可观测也在线，背靠谷歌云，起点就是生产级。但它有个躲不掉的问题：跟谷歌云和 Gemini 绑得比较紧，不锁模型这一轴要扣分，你想换厂商、换云，体感就没那么顺。生态在长，但目前更像谷歌栈用户的默认选择，通用性上打了折。第七。


---

## 12. 第6名 · Microsoft Agent Framework（合）

第六名，微软的 Agent Framework，重的一端。它来头不小——是 AutoGen 加 Semantic Kernel 两个项目正式合并的后继，一套统一框架同时吃 Python 和点 NET，会话状态、类型、遥测、检查点、人工审批，企业该有的都有，绑 Azure 的团队几乎是默认选择。扣分在"新"：四月才发正式版，还在快速演进，迁移和早期踩坑的成本得算进去。底子厚、但没长熟，第六。


---

## 13. 第5名 · OpenAI Agents SDK（合）

第五名，OpenAI Agents SDK，偏薄的一端。轻量派的标杆：交接、护栏、追踪，抽象干净、上手极快，零到能跑不用一小时，克制度这一轴很高分，是 OpenAI 生态里的默认起点。它的天花板也很清楚：复杂的状态管理和流程控制，它比重框架弱一截；而且虽然能接别家模型，气质上还是 OpenAI 优先。适合简单到中等的活，够用、顺手，但撑不起最重的场景。第五。


---

## 14. 第4名 · Agno（合·黑马）

第四名，Agno，原名 Phidata、后来改的名，四万一千星——这榜里被严重低估的一个，横跨库和平台两头。别只把它当库：它现在自称"agent 平台"，带一个自己的运行时，从开发、到高并发运行、到治理，想做一体化。主打轻量高性能，长任务、流式、可选的托管运行时都有，落地活性和生产就绪两轴都拿了高分。之所以没进前三，是它面铺得大、有些能力还在验证成熟度，不像头部那几个各有一个死磕到底的强场景。但势头这么猛，明年再排，它很可能往上窜。第四。


---

## 15. 第3名 · AgentScope（合·国产之光）

第三名，也是国产的最高位——阿里的 AgentScope，两万七千星，重的一端。它是我要重点捧的一个，因为它把"企业级"三个字落到了实处：安全沙箱、多租户隔离、细粒度权限、全栈可观测、弹性部署、还有把 agent 直接暴露成服务的接口，这套企业重装，大多数工具让你自己搭，它内置。生产企业就绪这一轴，它是全榜天花板。更狠的是语言——全池子只有它有一等公民的 Java，四千三百星的独立 Java 实现，国内企业后端是 Spring 和 Java 的天下，这条几乎是为国内企业量身的护城河。它唯一的代价是重：你做个知识库小助手，用不上这一整套。企业生产选它，个人小项目绕开它。第三，实至名归。


---

## 16. 第2名 · Pydantic AI（合·克制之王）

第二名，Pydantic AI。先说来头：它是 Pydantic 团队亲手做的，而 Pydantic 是 Python 里最流行的数据校验库，火到什么程度——大半个 Python 后端、连 FastAPI 的底层，都建在它身上。所以这帮人做 agent，类型安全是祖传手艺。它站在偏薄那一端，更像一个顺手的库，控制权还在你手里。如果说榜首赢在全，它赢在准和净。类型安全是它的信仰：围绕输入输出的强约束、严格校验，配上和你 Python 代码库一条心的开发体感，写起来干净、测起来放心，出了第二代之后势头很猛。四信号里的确定性类型，它就是标准答案。它不贪大、不做自己不擅长的，就把"类型化的可靠 agent"这一件事做到极致——这正是锐评官最偏爱的那种敢做减法。差榜首那一口气，是最复杂那类状态编排上，它还不如第一名厚。但论克制和可靠，它是我心里的第一。


---

## 17. 第1名·榜首 · LangGraph（合）

榜首，LangGraph，没有悬念。它是 LangChain 出品——LangChain 就是最早把"agent 框架"这个词带火的那家，LangGraph 是他们专门为可恢复、可控的复杂流程做的重框架标杆。核心编排力这一轴，它是天花板：状态图、可持久化、断点续跑、人工审批、流式，你能想到的复杂 agent 运行时需求，它几乎都给你正面硬扛，被大量团队当成今年的生产标准。四信号里的多 agent 编排和生产级可观测，它都是那个最稳的答案。它唯一挨刀的地方是上手：样板代码多、学习曲线陡，做个简单 agent 用它，就是典型的高射炮打蚊子——但这恰恰印证了主线：它是"复杂度真来了"才该请出的重武器。真到了该上重框架那一天，它是最不会让你后悔的那个。榜首，LangGraph。


---

## 18. 光谱最薄那端 · pi-agent-core（合·呼应暴论）

榜揭完了，但别忘了这期真正的主角，其实是那句暴论。如果你回头看四信号，发现一个都没咬到你——那恭喜，这整张重榜跟你没关系。这时候站光谱最薄那端最舒服，比如 pi-agent-core：几百行的 agent 循环，模型随便换、每一行自己掌控，没有任何你用不上的抽象。它不参与排名，因为它压根不是来跟重框架比工程完整度的——它代表另一种活法，也是大多数人该有的起点：先用最薄的把东西跑起来，等问题真逼你了，再往重的加。你一个小功能，站这端，就对了。


---

## 19. 选型落点·该上多重（合）

把整条光谱压成一句话，对号入座。小功能、自己掌控、不想被绑——最薄那端，pi-agent-core 这种极简内核。简单到中等、想省心又不重——偏薄的 OpenAI Agents SDK。要类型安全、Python 工程干净——Pydantic AI。要复杂状态、人工审批、生产级可控——重框架 LangGraph。国内企业、要 Java、要沙箱多租户上生产——AgentScope。一句话收口：需求有多重，工具就上多重，别拿高射炮打蚊子，也别拿弹弓打坦克。


---

## 20. 立场收尾（合）

最后说立场。这十个工具，没有一个是废物，但也没有一个是银弹。它们没死，只是你伸手去拿重框架的场景，比过去窄多了——因为工具、检索、循环这些中间件，正在被薄 SDK 一层层吃掉。真正难、真正值钱的，从来不是选哪个工具，而是你有没有想清楚：这个 agent 要跑在什么边界里、失败了能不能恢复、行为能不能追踪。诚实说明一句：这期是桌面研究加一手体感的主观段位，不是逐个搭一遍的实测跑分，星级仅供参考、欢迎理性讨论。


---

## 21. 收官·技能线预告（合·转场）

到这，工具标榜线，正式收官。从编程工具、到 AI 搜索、到云端 agent、到今天这条从 SDK 到框架的光谱，我们把"工具"这一层，扒了个底朝天。但有一条暗线：工具正在被商品化，人人都能调同样的能力，那真正拉开差距的护城河，早就上移到了 skills——你到底给 AI 装了什么本事。所以下一条线，我们正式开新篇：skills 线。什么是 skills？你可以把它理解成 AI 时代的 APP——给 Agent 装上一个 skill，它就多会一手；装一身 skills，它就拼成一个专属于你的 Agent。所以 skills 可不只是那些开发方法论包，那只是一小块。我们初步排的这一季，全是能实打实帮你省时间、少踩坑的实战 skills：教 AI 帮你把一团乱的 Excel 洗干净、几分钟做完一份能看的 PPT、跑一遍专业的数据分析；教它替你做深度研究、把网上信息的真假核验清楚；到了最硬核的那一块——帮你看懂一家公司的财报、给手里的基金和 ETF 做个体检、拆一份 A 股公告，甚至识破那些常见的割韭菜话术，让你别稀里糊涂就当了那个韭菜。一个 skill 一个本事，攒一身，就是别人抢不走的护城河。这一层，才是真正把普通人和高手拉开的地方。想跟上，关注一下，别走丢，skills 线马上开。
