## 逐页口播稿

### P2 · 开场（标尺 + 诚实补丁）
先把丑话说前头：这一期我没一个一个去实测——要把这十几个工具塞进一个公平的测试环境，够我录一整年。所以这是我**基于官方资料、代码库、公开评测，加上自己上手的体感**，给出的**主观排名**。你不用全信，但每个为什么排这儿，我都说给你听。
评分就五刀：上手快不快、能力够不够硬、生态活不活、**带不带得走**、值不值这个钱。其中"值不值"这一刀，这一期我专门去抠了各家的**额度和套餐**——因为对花钱的人，这才是真痛点。
十一个工具，外加一个压轴的极客神器。从夯到拉，倒数开始。

### P3 · 第11名 · 通义灵码（阿里）
第十一名，阿里的通义灵码。免费、自动记忆、阿里云生态焊得死死的，Java、Go 用着顺。但我说句得罪人的：它装机量第一，**真天天离不开它的人，你数数有几个？** 它什么都对——稳、免费、能记事——就是没给你一个"非它不可"的理由。阿里云、国企、Java 团队闭眼装；出了这个圈，它容易在你电脑里吃灰。

### P4 · 第10名 · ZCode（智谱）
第十名，智谱的 ZCode。很多人以为它把你锁死在智谱全家桶里——**其实不是。** 它默认配自家 GLM（便宜、目前还有 150% 促销、新人送五天），但你完全可以拿 API key 给它接别家模型，OpenAI、Anthropic 协议都兼容。**所以它的真实定位是：智谱出的、默认吃 GLM 套餐最划算、但不把你焊死的一个新工具。** 吃 GLM 的人首选，别人也能拿它当个便宜的多模型壳子——就是还新，再观察观察。

### P5 · 第9名 · CodeBuddy（腾讯）
第九名，腾讯的 CodeBuddy。混元模型、全免费、IDE 和命令行都有。它真正的杀手锏其实就一个——**微信小程序**，那套生态里它顺得没话说。但你品品，这是"技术领先"还是"生态绑定"？出了微信这一亩三分地，它就泯然众人。**你靠微信小程序吃饭，它是宝；不是，那它对你就是个平平无奇的补全器。**

### P6 · 第8名 · GitHub Copilot（微软）
第八名，微软的 GitHub Copilot。先纠正一个过时印象：它早不是当年那个"只会帮你补下一行"的补全工具了——现在有 agent mode 能多文件自主干活、有云端 coding agent 能接 issue 直接提 PR、还能切 Claude、GPT、Gemini 好几家模型，从免费到 Pro、Pro+ 五档套餐齐全。能力，它补上了。那为什么还在第八？因为它**样样都有、样样不拔尖**——论 agentic 深度不如 Claude、Codex，论顺手不如 Cursor，它赢的是"背靠 GitHub、企业无脑选、最稳妥"。而且 2026 它也转向了按量计费，agent 一用猛，账单照样能吓你一跳。**大厂、GitHub 重度、要稳要合规的团队，它是默认答案；但你想要某一项最强，它哪项都不是。**

### P7 · 第7名 · Qoder（阿里）
第七名，阿里的 Qoder。这个我得说句公道话——方向是对的：仓库级理解、长期记忆，奔着"啃真实大项目"去的，不是玩具。问题是它还年轻，而且尴尬的是，它跟自家通义灵码**左右手互搏**——阿里一口气塞你两把刀，你反而不知道抄哪把。**大仓库、长任务、中文团队，值得盯；但现在押注它，你得接受它还在长身体。**

### P8 · 第6名 · Cursor
第六名，Cursor。我知道，很多人心里它是第一。体验确实最顺，Composer 多文件一起改，丝滑。但听我说——**它好用到你忘了自己在租。** 2025 年那次静默涨价，等效翻了二十倍、CEO 出来道歉、还得退款——那一次，把"你的工作流攥在别人手里"演得明明白白。**它越顺手，你越该问一句：哪天它再变一次脸，你跑得掉吗？**

### P9 · 第5名 · Google Antigravity（反重力）
第五名，谷歌的 Antigravity，反重力。配 Gemini，**快得飞起**；2.0 之后额度大方了不少，谷歌 Pro 的渠道又好搞——快、便宜、额度管够，这三样我服，所以我把它排在 Cursor 前面。但有个补丁我必须打：**它的额度，像谷歌的心情**——五小时刷新能突然变三天，涨了被骂、骂了再涨。更别提，三个月前 Firebase Studio 还活着呢，现在让你迁走的就是它。**当尝鲜主力、吃它的速度和便宜，可以；把三年身家压上去，我劝你想想谷歌那座产品墓地。**

### P10 · 第4名 · Trae（字节）
第四名，字节的 Trae。名气不小、还免费，可我没把它放进前三——因为它的"免费"有个**星号**。国内首款 AI 原生 IDE、中文、SOLO 能自己跑，入门确实香；但**高峰期它排队能排到半小时、甚至排满**，要顺畅，要么买它十块钱的快速通道、要么自己接个 API 进去。所以它仍是**国内轻量上手的首选**，但你要拿它当生产主力，得做好"要么等、要么掏钱"的心理准备。免费党尝鲜可以，重度别硬扛。

### P11 · 第3名 · OpenAI Codex
第三名，OpenAI 的 Codex。真能干活的那一档——你可以扔给它一坨大重构，关上电脑去喝咖啡，回来它在沙箱里给你弄得七七八八。额度这块它最近翻了倍，听着大方；但社区一直吐槽它那个"五小时窗口"口径不透明，重度用着用着就撞墙，而且你得先有 ChatGPT 的 Plus 或 Pro。**能力在线，额度有点雾、门票有点绕。** 已经在 OpenAI 生态里，它顺理成章；不在，为它单独折腾，想清楚值不值。

### P12 · 第2名 · OpenCode
第二名，OpenCode。把账算明白之后，它是这一榜里我最想安利给你的一个。全网 star 最多的开源 agent，十七万。重点是**性价比**：它有个套餐叫 OpenCode Go，**首月五美元、之后十块钱一个月**，给你一大把模型、一周六千万 token——被叫做 2026 年最便宜的多模型订阅；嫌套餐麻烦，还有个 Zen，按量付费、**零加价**。再加上能接任何模型、能离线。你发现没有——前面那些闭源货都在锁你、涨你的价，**就它，又便宜又带得走。** 短板还是那个：它不替你拿主意，你得自己懂行。**愿意花十分钟搞懂它的人，这是这一榜里最划算的选择。**

### P13 · 第1名 · Claude Code
第一名，Claude Code。没有悬念——复杂的、跨多文件、要动脑子的活，它是真能给你干完，不是演个 demo。这一年，别的工具都在追它定的那条线。但我得给你打个**诚实补丁**：它的额度这半年被砍得肉疼，免费和 Pro 动不动就撞墙，真要爽用，你得上 Max——一个月一百到两百刀。所以它是天花板，**也是这榜里最烧钱的天花板。** 靠写代码吃饭、又付得起、又能解决访问的，它无敌；预算紧的，回头看第二名。

### P14 · 总榜 reveal
十一个排完，一张图收齐。夯到拉，从上往下。记不住没关系，**记住三句话就够：真要干硬活又烧得起，Claude Code；又便宜又带得走，OpenCode；国内轻量入门、不想花钱，Trae——但做好排队的准备。** 其余的，看你是谁。

### P15 · 压轴 · 极客之选 Pi
最后，压轴。这个不进大众排名，因为它压根不是给大多数人的——**极客特别奖，Pi。** 一个嫌所有 agent 都太臃肿的人，自己撸的最小核：就读、写、改、跑四个工具，剩下全靠你喂 skill 文件给它长本事。普通人碰它会崩溃；但那种"我就要自己捏一把趁手兵器"的极客，会爱死它。**它不适合你——除非你看完这句话，眼睛是亮的。**（顺嘴：它还是某个常驻 Agent 系统的底层内核，那是我们下一条线的故事了。）
